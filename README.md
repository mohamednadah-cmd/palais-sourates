# Le Palais des Sourates

Application web pour aider des enfants à apprendre par cœur 15 courtes sourates :
écoute du verset (3 fois), récitation vérifiée par le micro, histoire et morale en cartes, quiz, personnage à habiller.

Ouvrir sur l'iPad dans Safari, puis Partager › « Sur l'écran d'accueil ».
